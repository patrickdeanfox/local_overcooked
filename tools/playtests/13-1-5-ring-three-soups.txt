# -- 1-5: the ring. Two chefs circling the same way, one soup out of each of the three pots --
#
# The oval is one tile wide, so the only stable way to run it is a pipeline. Three waypoints
# split the loop and a chef only ever walks an arc the other chef is not standing in:
#   W1 (1,1)   top-left, under the mushroom crate
#   W2 (8,6)   bottom-middle, at the first pot
#   W3 (12,1)  top-right, beside the bin
# The three arcs all run the SAME way round (down the left, right along the bottom, up the
# right, left along the top):
#   A1  W1 -> W2   down column 1, chop on a board at (1,7) or (3,7), on along row 6
#   A2  W2 -> W3   right along row 6 past the pots at (10,7) and (12,7), up column 12
#   A3  W3 -> W1   left along row 1 past the sink, the hatch and the crates
# Station order round the loop is crate -> board -> pot -> plate -> hatch -> crate, so one lap
# is one ingredient and the chefs never have to turn back.
#
# Two chopped ingredients per soup are parked on the island counters at (7,5)/(8,5) (and later
# (9,5)/(10,5), free once their plates have been used) and the third chef tips all three in
# together. Filling a pot one lap at a time does not work: a pot cooks as soon as ANY
# ingredient is in it and catches fire BURN_TIME after that, which is less than two laps.
#
# Menu: Seed number +2 (1 -> 3, which also pins the mode to fixed), Free play on, then 1-5.
# Seed 3 opens with a mushroom and an onion ticket and adds a tomato one at 20 s.
